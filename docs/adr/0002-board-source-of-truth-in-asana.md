# 看板のデータの正は Asana に置き、DB は写しにする

devloop の看板は、Asana のプロジェクトのセクションを列とする。項目の meta (点数・仮説・Jev の採点など) は、Asana のタスクの notes に `<!-- devloop ... -->` として埋め込む。アプリの DB は表示と検索のための写しにとどめる。

meta を DB の列に持たせる方が扱いやすいが、そうしなかった。「アプリの DB は消えても GitHub と Asana から作り直せる」という、このアプリの最初からの原則を守るためである。持ち主が Asana で直接項目を動かしても、看板と食い違わないという利点もある。

## Consequences

- meta の読み書きは notes の解析を通る。持ち主が notes を手で書き換えて印を壊すと、その項目の meta は空として扱う。
- 列の移動や meta の更新は、Asana の API を同期で呼ぶ。そのため、ツール 1 回の応答は Asana の速さに左右される。
- 写しは Asana の Webhook と、ツールで書いた直後の読み直しで最新に保つ。
