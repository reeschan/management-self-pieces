# PBI-009: GitHub Webhook と定期取り込み (Cron)

- 担当モデル: opus (select_model.py: sensitive; scores {'novelty': 1, 'coupling': 1, 'ambiguity': 0})
- 依存: PBI-008

## 目的
リポジトリに push されたら、そのリポジトリの node.yaml を取り込み直す。GitHub App にリポジトリが追加・削除されたときも反映する。取りこぼしの補完として、Vercel Cron で 1 日 1 回すべてを取り込み直す。どちらの入口も公開 URL なので、**署名 (Webhook) と秘密のトークン (Cron) を必ず検証する**。

### webhook.ts (純粋関数)
```ts
export type GithubAction =
  | { kind: "import-repo"; repos: string[] }  // 取り込み直すリポジトリ (fullName)
  | { kind: "ignore"; reason: string };
export function decideGithubAction(event: string, payload: unknown): GithubAction;
export function isAuthorizedCron(authorization: string | null, cronSecret: string): boolean;
```
- `push`: `payload.ref` が `refs/heads/<payload.repository.default_branch>` のときだけ `import-repo` (`[payload.repository.full_name]`)。それ以外は ignore
- `installation_repositories`: `repositories_added` と `repositories_removed` の `full_name` をすべて `import-repo` に (削除されたリポジトリは importRepo が「App が入っていない」と判断して Node を消す)
- `installation` で `action` が `deleted`: その `repositories` の `full_name` を `import-repo` に
- `ping` やその他: ignore
- payload の形は Zod で必要な項目だけ検証し、合わなければ ignore (例外を投げない)
- `isAuthorizedCron`: `authorization === "Bearer " + cronSecret` を**長さの違いも含めて定数時間で**比べる (`crypto.timingSafeEqual`。長さが違えば false)

### api/webhooks/github/route.ts (`POST`)
1. 本文を `await req.text()` で生のまま読む
2. `@octokit/webhooks-methods` の `verify(githubEnv().webhookSecret, body, req.headers.get("x-hub-signature-256") ?? "")` が false なら 401
3. `decideGithubAction(req.headers.get("x-github-event") ?? "", JSON.parse(body))`
4. `import-repo` なら各リポジトリに `runRepoImport` を順に実行し、結果の合計を JSON で 200 で返す。ignore なら `{ ignored: reason }` を 200
- `export const runtime = "nodejs"`

### api/cron/import/route.ts (`GET`)
- `isAuthorizedCron(req.headers.get("authorization"), cronEnv().cronSecret)` が false なら 401
- `runFullImport()` の結果を JSON で返す
- `export const runtime = "nodejs"`、`export const maxDuration = 60`

### vercel.json
```json
{ "crons": [{ "path": "/api/cron/import", "schedule": "0 18 * * *" }] }
```
(Vercel Cron は `CRON_SECRET` を Authorization: Bearer で付けて呼ぶ。Hobby プランは 1 日 1 回まで)

## 受け入れ条件
1. 検証コマンド 1 が終了コード 0 で、テストがすべて pass する。少なくとも次を含む
   - default branch への push → import-repo、別ブランチへの push → ignore
   - installation_repositories の追加と削除の両方の full_name が入る
   - installation の deleted → import-repo
   - ping、形の合わない payload → ignore (例外を投げない)
   - isAuthorizedCron: 正しいトークンで true、違うトークン・長さ違い・null で false
2. 検証コマンド 2 が終了コード 0
3. 検証コマンド 3 が終了コード 0
4. 検証コマンド 4 の出力が 1 以上 (Webhook の route で署名を検証している)
