# PBI-014: Node の詳細 API とリポジトリ内ファイルの配信

- 担当モデル: opus (select_model.py: sensitive; scores {'novelty': 0, 'coupling': 2, 'ambiguity': 0})
- 依存: PBI-005, PBI-007, PBI-008

## 目的
詳細パネル (PBI-015) が表示する情報を返す API を作る。詳細の Markdown とアーキ図 (SVG など) は各リポジトリにあり、非公開リポジトリもあるので、アプリが Installation Token で読み、ログイン中の持ち主にだけ返す。**読ませてよいのは node.yaml に書かれた `detail` と `diagrams` のパスだけ**にし、リポジトリ内の任意のファイルを読めないようにする。

## 対象
- 新規 `src/lib/nodes/asset.ts`: 純粋関数
- 新規 `src/lib/nodes/asset.test.ts`
- 新規 `src/lib/nodes/detail.ts`: `loadNodeDetail(id)`
- 新規 `src/app/api/nodes/[id]/route.ts` (`GET`)
- 新規 `src/app/api/nodes/[id]/asset/route.ts` (`GET`)

### asset.ts
```ts
export type AssetKind = "markdown" | "svg" | "png" | "jpeg" | "webp" | "mermaid";
export function assetKindOf(path: string): AssetKind | null;   // 拡張子 .md .svg .png .jpg/.jpeg .webp .mmd (大文字小文字を無視)。それ以外は null
export function contentTypeOf(kind: AssetKind): string;        // markdown/mermaid は text/plain; charset=utf-8、svg は image/svg+xml など
export function isAllowedAsset(node: { detailPath: string; diagrams: { path: string }[] }, path: string): boolean;
// path が detailPath か diagrams[].path のどれかと完全一致し、かつ assetKindOf が null でないときだけ true
export function isGithubSource(sourceRepo: string): boolean;   // "owner/name" の形 (fixtures/ で始まるものは false)
```

### detail.ts
`loadNodeDetail(id: string)` は次の形を返す。Node が無ければ null。
```ts
{
  node: { id, kind, title, summary, status, tags, links, sourceRepo, updatedAt },
  detail: { path: string; markdown: string | null },   // GitHub のリポジトリでなければ markdown は null
  diagrams: { path: string; title: string | null; kind: AssetKind; url: string }[], // url は /api/nodes/<id>/asset?path=<encodeURIComponent(path)>
  asana: { projectId: string; url: string | null } | null,   // external_refs の asana
  tasks: { externalId, name, completed, dueOn, url }[],      // task_cache。未完了を先に、その中は dueOn の早い順 (null は後)
  importErrors: { path: string; message: string }[],         // その Node の sourceRepo の import_errors
}
```
- 詳細の Markdown は `createRepoSource()` の `getRepo` で default branch を取り、`getFile` で読む。読めない (null・例外) ときは markdown を null にし、例外を外に出さない
- `kind` が null になる diagram は一覧から除く

### api/nodes/[id]/route.ts
- `getSession()` が null なら 401
- `loadNodeDetail` が null なら 404、それ以外は JSON で返す

### api/nodes/[id]/asset/route.ts
- `getSession()` が null なら 401
- Node が無い、`path` クエリが無い、`isAllowedAsset` が false、`isGithubSource` が false なら 404
- `getRawFile` でバイト列を読み、無ければ 404
- ヘッダー: `Content-Type` は `contentTypeOf`、`Cache-Control: private, max-age=300`、`X-Content-Type-Options: nosniff`、SVG のときは追加で `Content-Security-Policy: default-src 'none'; style-src 'unsafe-inline'; img-src data:` (SVG 内のスクリプトを動かさない)
- `export const runtime = "nodejs"`
