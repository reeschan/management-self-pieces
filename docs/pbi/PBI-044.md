# PBI-044: IP 許可リスト (CIDR の判定と DB の読み書き)

- 担当モデル: codex high（sonnet 相当） (select_model.py: 決定: sonnet。novelty・coupling・ambiguity のどれかが 1 以上（2026-10-23 までは codex を agy より先に試す）; scores {'novelty': 0, 'coupling': 1, 'ambiguity': 0})
- 依存: PBI-041, PBI-042

## 目的
ホストで動くとき、MCP の口は IP 許可リストに含まれる送信元だけを通す。CIDR の検証・正規化・包含の判定 (IPv4 / IPv6) と、DB の許可リストの読み書きを作る。許可リストが空なら、すべて拒否する。

## 対象
- 新規 `src/lib/mcp/ip.ts` (DB を触らない純粋な関数)
  - `export function normalizeCidr(input: string): string | null`
    - `"203.0.113.5"` → `"203.0.113.5/32"`、`"203.0.113.0/24"` → そのまま、`"2001:db8::1"` → `"2001:db8::1/128"`
    - IPv4 の接頭辞長は 8〜32、IPv6 は 32〜128 だけを受け付ける (それより広い範囲は null。誤って全開にしないため)
    - 不正な文字列、前後の空白以外のゴミ、接頭辞長の範囲外は null
  - `export function cidrContains(cidr: string, ip: string): boolean`: IPv4 射影アドレス (`::ffff:203.0.113.5`) は IPv4 として扱う。不正な入力は false
  - `export function isLoopback(ip: string): boolean`: `127.0.0.0/8`、`::1`、`::ffff:127.x.x.x`
  - `export function allowEntryFor(ip: string): string | null`: 「今の IP を許可」で登録する範囲。IPv4 は `/32`、IPv6 はその IP を含む `/64` のネットワークアドレス (例 `2001:db8:1:2:3:4:5:6` → `2001:db8:1:2::/64`)。不正なら null
  - 実装は Node の `net.isIP` と `net.BlockList` (`addSubnet` と `check`) を使ってよい
- 新規 `src/lib/mcp/ip-allowlist.ts` (`AppDb` を引数に取る)
  - `listAllowlist(db)`: 作成の古い順。`{ id, cidr, label, createdAt }`
  - `addAllowlistEntry(db, input: { cidr: string; label: string })`: `normalizeCidr` を通し、null なら例外。label は前後の空白を除いて 1〜60 文字。同じ cidr が既にあれば何もしない (重複で例外にしない)。正規化後の cidr を返す
  - `removeAllowlistEntry(db, id: number): Promise<boolean>`
  - `isIpAllowed(db, ip: string): Promise<boolean>`: 1 行も無ければ false。どれかの cidr が `ip` を含めば true
- 新規 `src/lib/mcp/ip.test.ts` (純粋な関数のテスト) と `src/lib/mcp/ip-allowlist.test.ts` (`createTestDb()` を使う)

## 受け入れ条件
1. 検証コマンド 1 が終了コード 0。少なくとも次を確かめる
   - `normalizeCidr`: 上の 3 例、`"0.0.0.0/0"` と `"::/0"` と `"10.0.0.0/7"` が null、`"abc"` が null
   - `cidrContains`: 範囲の内と外、IPv4 射影アドレス、v4 の範囲に v6 の IP (false)
   - `isLoopback`: `127.0.0.1`・`::1`・`::ffff:127.0.0.1` が true、`192.168.0.1` が false
   - `allowEntryFor`: IPv4 と IPv6 の例
