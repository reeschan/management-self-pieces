# PBI-048: `/api/mcp` のルートと、cron での古い行の削除

- 担当モデル: agy claude-opus-5-5-high（opus 相当） (select_model.py: 決定: opus。sensitive; scores {'novelty': 0, 'coupling': 0, 'ambiguity': 0})
- 依存: PBI-047

## 目的
PBI-047 のハンドラーを、Next.js のルート `/api/mcp` として公開する。送信元 IP は Vercel の関数用パッケージで取る。あわせて、毎日の cron で、90 日を過ぎた監査ログと古い回数の行を消す。

## 対象
- 新規 `src/app/api/mcp/route.ts`
  - `export async function POST(req: Request)` だけを export する (GET などは export しない。Next が 405 を返す)
  - `handleMcpRequest(req, { db: getDb(), mode: runtimeMode(), clientIp: ipAddress(req) ?? null, now: () => new Date() })` を返す
  - `ipAddress` は `@vercel/functions`、`runtimeMode` は `@/lib/env`、`getDb` は `@/db/client`、`handleMcpRequest` は `@/lib/mcp/handler`
  - 想定外の例外は `console.error` に出して 500 (`{"error":"internal error"}`)。中身を返さない
  - `export const maxDuration = 30;`
- 変更 `src/app/api/cron/import/route.ts`
  - 取り込み (`runFullImport`) の後で、`purgeAudit(getDb(), now)` と `purgeRateLimits(getDb(), now)` を呼ぶ
  - 削除の失敗は `console.error` に出すだけにし、取り込みの結果の応答は変えない (削除の失敗で cron を 500 にしない)
  - 応答の JSON に `auditPurged` と `rateLimitsPurged` (件数。失敗したら null) を足す

## 触らない範囲
- `src/lib/mcp/` の各モジュール
- cron の認証 (`isAuthorizedCron`) と、取り込みの処理・エラー処理
- ほかのルート

## 受け入れ条件
1. 検証コマンド 1 の出力が `1` (route.ts が export する関数は POST だけ)
2. 検証コマンド 2 の出力が `2` (cron で 2 つの削除を呼ぶ)
3. 検証コマンド 3 が終了コード 0
4. 検証コマンド 4 が終了コード 0
5. 検証コマンド 5 が終了コード 0 (環境変数なしでビルドが通る)

## 検証コマンド
1. `grep -cE "^export (async )?function" src/app/api/mcp/route.ts`
2. `grep -cE "purgeAudit\(|purgeRateLimits\(" src/app/api/cron/import/route.ts`
3. `pnpm typecheck`
4. `pnpm lint`
5. `pnpm build`

## 補足
- **この Next.js (16.4) は学習データと違う点がある。** 書く前に `node_modules/next/dist/docs/01-app/01-getting-started/15-route-handlers.md` と `node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/route.md` を読むこと
- 既存のルート (`src/app/api/cron/import/route.ts`、`src/app/api/webhooks/asana/route.ts`) の書き方に合わせる。環境変数はモジュールの読み込み時に読まない (`getDb()` も `runtimeMode()` もハンドラーの中で呼ぶ)。読み込み時に読むと、環境変数なしの `pnpm build` が落ちる
- `ipAddress` はリクエストのヘッダーから IP を返す (Vercel 以外では undefined になりうる)。ローカルでは IP を使わないので null で構わない
- コメントは日本語。コミットはしない
