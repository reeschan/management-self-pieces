# PBI-050: 設定画面 (トークン・IP 許可リスト・監査ログ) とヘッダーのリンク

- 担当モデル: codex high（sonnet 相当） (select_model.py: 決定: sonnet。files_changed=4 >= 4（2026-10-23 までは codex を agy より先に試す）; scores {'novelty': 0, 'coupling': 0, 'ambiguity': 0})
- 依存: PBI-049, PBI-045

## 目的
持ち主が、エージェント用トークン・IP 許可リスト・監査ログを画面で扱えるようにする。トークンの値は、発行した直後に一度だけ表示する。ヘッダーにダッシュボードと設定へのリンクを置く。

## 対象
- 新規 `src/app/(app)/settings/page.tsx` (サーバーコンポーネント)
  - `await connection()` してから DB を読む (既存の `src/app/(app)/page.tsx` と同じ)
  - 見出し「設定」と、今の動作モード (`runtimeMode()`)。ローカルのときは「ローカルで動いているので、MCP の口はトークンと IP 許可リストを使わない」と注記する
  - 「エージェント用トークン」の節: `listTokens(getDb())` を `TokenSection` に渡す
  - 「IP 許可リスト」の節: `listAllowlist(getDb())` を `IpSection` に渡す
  - 「監査ログ」の節: `searchParams` の `rejected=1` で絞り込む。`listAudit(getDb(), { onlyRejected, limit: 100 })` を表にする (時刻・モード・トークン名 (トークン ID から listTokens で引く。無ければ `-`)・IP・ツール・結果・理由・所要時間・引数の要約)。「すべて / 拒否だけ」の切り替えリンク
- 新規 `src/components/settings/token-section.tsx` (`"use client"`)
  - 一覧: 名前・権限・期限・最終使用・状態 (有効 / 期限切れ / 失効)。有効なものに「失効」ボタン (確認ダイアログ付き)
  - 発行フォーム: 名前、権限のチェックボックス (read / board / loop。read は既定でオン)、期限 (30 日 / 90 日 / 365 日 / なし。既定 90 日)
  - 発行に成功したら、値を読み取り専用の欄とコピーボタンで出し、「この値は二度と表示されない」と警告する。値は React の state にだけ置き、localStorage などに保存しない。閉じたら消す
  - Claude Code への登録例を出す: `claude mcp add --scope user --transport http pieces <APP の URL>/api/mcp --header "Authorization: Bearer ${PIECES_AGENT_TOKEN}"` (URL は `window.location.origin` から作る)
- 新規 `src/components/settings/ip-section.tsx` (`"use client"`)
  - 一覧: CIDR・名前・登録日時、「削除」ボタン
  - 追加フォーム: CIDR と名前
  - 「今の IP を許可」ボタン (名前の入力付き。既定は「今の IP」)
  - 許可リストが空のときは「空のあいだ、ホストの MCP の口はすべての呼び出しを拒否する」と出す
  - Server Action のエラーの message を画面に出す
- 変更 `src/app/(app)/layout.tsx`: ヘッダーの左側に「ダッシュボード」(`/`) と「設定」(`/settings`) のリンク (`next/link`) を足す。右側のメールアドレスとログアウトはそのまま

## 触らない範囲
- `src/app/(app)/settings/actions.ts` (使うだけ)、`src/lib/mcp/`
- `src/app/(app)/layout.tsx` のセッションと許可リストの確認
- ダッシュボードと Node のパネル

## 受け入れ条件
1. 検証コマンド 1 の出力が `1` 以上 (layout に /settings へのリンクがある)
2. 検証コマンド 2 の出力が空 (トークンの値をブラウザの保存領域に置いていない)
3. 検証コマンド 3 が終了コード 0
4. 検証コマンド 4 が終了コード 0
5. 検証コマンド 5 が終了コード 0 (環境変数なしでビルドが通る)

## 検証コマンド
1. `grep -c 'href="/settings"' "src/app/(app)/layout.tsx"`
2. `grep -nE "localStorage|sessionStorage|indexedDB" src/components/settings/token-section.tsx`
3. `pnpm typecheck`
4. `pnpm lint`
5. `pnpm build`
