# PBI-061: Tracker に看板の操作を足す (型と Asana の実装)

- 担当モデル: agent opus（opus 相当） (select_model.py: 決定: opus。coupling=2; scores {'novelty': 1, 'coupling': 2, 'ambiguity': 0}。route 先頭の agy は使用不可のため agent)
- 依存: なし

## 目的
devloop の看板は Asana のセクションを列にし、タスクの notes・タグ・コメントを使う。Tracker の型と Asana の実装に、そのための操作を足す。復元した `R/lib/tracker/asana.ts` が土台 (型の定義ファイルは失われたので、使い方から作り直す)。足りなかった「1 件の取得」と「コメントの一覧」も足す。

## 対象
- 変更 `src/lib/tracker/types.ts`
  - `TrackerSection = { externalId: string; name: string }`
  - `TrackerTaskDetail = TrackerTask & { notes: string; tags: string[]; sectionId: string | null; sectionName: string | null; assigneeId: string | null }`
  - `TrackerComment = { externalId: string; text: string; authorId: string | null; createdAt: string }`
  - `TaskInput` に `assigneeId?: string`、`sectionId?: string` を足す
  - `TrackerProvider` に足すメソッド:
    - `listSections(projectId): Promise<TrackerSection[]>`
    - `createSection(projectId, name): Promise<TrackerSection>`
    - `listTaskDetails(projectId): Promise<TrackerTaskDetail[]>`
    - `getTask(taskId): Promise<TrackerTaskDetail>`
    - `moveTask(taskId, sectionId): Promise<void>`
    - `updateTask(taskId, patch: { name?: string; notes?: string; assigneeId?: string | null }): Promise<TrackerTaskDetail>`
    - `ensureTag(name): Promise<string>` (タグの gid)
    - `addTag(taskId, tagId): Promise<void>`
    - `addComment(taskId, text): Promise<void>`
    - `listComments(taskId): Promise<TrackerComment[]>`
- 変更 `src/lib/tracker/asana.ts`: `R/lib/tracker/asana.ts` の対応するメソッドを戻し、次を足す
  - `getTask`: `GET /tasks/{gid}` (opt_fields は `listTaskDetails` と同じ)
  - `listComments`: `GET /tasks/{gid}/stories` (opt_fields `text,created_by.gid,created_at,resource_subtype`)。`resource_subtype === "comment_added"` のものだけを返す
  - `createTask` は `assigneeId` と `sectionId` を受け付ける (R のとおり、memberships でセクションを指定)
  - `ensureTag` のキャッシュは、R と同じく provider のインスタンスの中だけ
- 新規 `src/lib/tracker/asana-board.test.ts`: `tracker.test.ts` と同じ偽の `fetch` で、足したメソッドごとに「呼ぶ URL・メソッド・送る本文」と「返す形」を確かめる

## 触らない範囲

- `src/lib/tracker/service.ts`、`marker.ts`、`signature.ts`、既存の `tracker.test.ts`
