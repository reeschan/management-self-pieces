# PBI-071: devloop の画面の Server Actions

- 担当モデル: agent opus（opus 相当） (select_model.py: 決定: opus。sensitive; scores {'novelty': 0, 'coupling': 0, 'ambiguity': 0}。route 先頭の agy は使用不可のため agent)
- 依存: PBI-065, PBI-066

## 目的
画面から devloop を操作するための Server Actions を作る。看板の準備 (Asana につなぎ、8 列を作る)、Node ごとの設定と一時停止・再開、全体停止と 1 日の上限、Owner 判断への回答。

## 対象
- 新規 `src/app/(app)/devloop/actions.ts` (`"use server"`)。どの関数も最初に `getAllowedSession()` を確かめ、null なら `throw new Error("unauthorized")`。最後に `revalidatePath("/")` (受け箱と設定画面を使う関数は、それぞれのパスも)
  - `prepareBoard(nodeId)`: 既存の `linkNodeToAsana` (`@/lib/tracker/service`) でプロジェクトをつなぎ (無ければ作り)、`board.ensureSections(nodeId)` で列を用意する
  - `updateDevloopSettings(nodeId, patch)`: `SettingsPatchSchema` で検証して `control.updateSettings`
  - `pauseNode(nodeId, reason)` / `resumeNode(nodeId)`
  - `setGlobalStop(on: boolean, reason: string | null)` / `setDailyLimit(n: number)` (1〜20)
  - `answerOwnerDecision(nodeId, itemId, text)`: `board.answerOwner` (本文は 1〜5,000 文字)
  - サービスは `createBoardService({ db: getDb(), tracker: getTracker(), ownerAssigneeId: asanaOwnerGid() ?? undefined })` と `createControlService({ db: getDb() })` で作る
  - `nodeId` は `NodeId` (`@/lib/manifest/schema`) で検証する
  - `BoardLimitError` と `BoardError` は、利用者向けの日本語のメッセージの Error に変えて投げ直す。それ以外の例外は、message を `"処理に失敗しました"` にして投げ直す (中身は `console.error` に出す)

## 触らない範囲
- 既存の `src/app/(app)/actions.ts`、`src/app/(app)/settings/actions.ts`
- `src/lib/devloop/` (使うだけ)

3. 検証コマンド 3 が終了コード 0
