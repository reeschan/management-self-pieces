# PBI-072: Node のパネルに「看板」「開発ループ」「イテレーション」のタブを足す

- 担当モデル: codex high（sonnet 相当） (select_model.py: 決定: sonnet。files_changed=4 >= 4（2026-10-23 までは codex を agy より先に試す）; scores {'novelty': 0, 'coupling': 0, 'ambiguity': 0})
- 依存: PBI-070, PBI-071

## 目的
持ち主が Node ごとに devloop の様子を見て操作できるよう、詳細パネルに 3 つのタブを足す。データは `GET /api/nodes/<id>/devloop` (PBI-070)、操作は `src/app/(app)/devloop/actions.ts` (PBI-071)。

## 対象
- 変更 `src/components/panel/node-panel.tsx`: `TABS` に「看板」「開発ループ」「イテレーション」を足し、それぞれのタブで下の部品を描く。3 つのうちどれかを初めて開いたときに `/api/nodes/<id>/devloop` を fetch する (既存の詳細の fetch と同じく AbortController で古い結果を捨てる)。操作の後は取り直す
- 新規 `src/components/panel/devloop/board-tab.tsx` (`"use client"`)
  - Asana につながっていなければ「看板を用意する」ボタン (`prepareBoard`)
  - つながっていれば列ごとに項目を並べる (名前・タグ・meta の value / effort があれば表示・Asana へのリンク)。meta の読み取りエラーがあれば小さく警告を出す。Asana のプロジェクトへのリンク
- 新規 `src/components/panel/devloop/loop-tab.tsx` (`"use client"`)
  - 有効/無効、自律度 (L0〜L3 の選択と短い説明)、1 日の上限、1 周の PBI の上限、Sprint の上限を変えるフォーム (`updateDevloopSettings`)
  - 一時停止中なら理由と「再開」、動いていれば理由を入力して「一時停止」
  - 全体停止中なら、その旨と理由を目立つように出す (変更は設定画面で行う、と案内)
  - 実行の記録 (時刻・フェーズ・結果・要約) を新しい順に表で出す
- 新規 `src/components/panel/devloop/iterations-tab.tsx` (`"use client"`)
  - イテレーションを番号の新しい順に並べる。番号・ゴール・フェーズ・結果・PR へのリンク・ストーリー (id・タイトル・状態) を出す
- Server Action のエラーの message を画面に出す。日時は日本時間で出す

## 触らない範囲
- 既存の 5 つのタブの中身と、パネルの開閉・ヘッダー
- `src/app/`・`src/lib/` (使うだけ)

## 受け入れ条件
1. 検証コマンド 1 の出力が `3` (3 つのタブ名が `TABS` にある)
2. 検証コマンド 2 が終了コード 0
3. 検証コマンド 3 が終了コード 0
4. 検証コマンド 4 が終了コード 0

## 検証コマンド
1. `grep -oE '"(看板|開発ループ|イテレーション)"' src/components/panel/node-panel.tsx | sort -u | wc -l`
2. `pnpm typecheck`
3. `pnpm lint`
4. `pnpm build`
