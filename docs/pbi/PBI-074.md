# PBI-074: 設定画面に devloop の全体停止と 1 日の上限を足す

- 担当モデル: codex high（sonnet 相当） (select_model.py: 決定: sonnet。modules=2 >= 2（2026-10-23 までは codex を agy より先に試す）; scores {'novelty': 0, 'coupling': 0, 'ambiguity': 0})
- 依存: PBI-071

## 目的
すべての Node の devloop をまとめて止めるスイッチと、全体の 1 日あたりのイテレーションの上限を、設定画面から変えられるようにする。

## 対象
- 新規 `src/components/settings/devloop-section.tsx` (`"use client"`)
  - 全体停止の状態 (止まっているか・理由) と、「全体を止める」(理由の入力付き) / 「再開する」ボタン (`setGlobalStop`)
  - 1 日あたりの上限 (1〜20) のフォーム (`setDailyLimit`)
  - 全体停止中は、目立つ色で「すべての Node の devloop が止まっている」と出す
  - Server Action のエラーの message を出す
- 変更 `src/app/(app)/settings/page.tsx`: 「devloop」の節を足し、`createControlService({ db: getDb() })` の `getGlobalStop()` と `getDailyLimit()` の値を `DevloopSection` に渡す。既存の節の並びの先頭に置く (止めるスイッチを見つけやすくするため)

## 触らない範囲
- 設定画面の既存の節 (トークン・IP 許可リスト・監査ログ) の中身
- `src/app/(app)/devloop/actions.ts` (使うだけ)

## 受け入れ条件
1. 検証コマンド 1 の出力が `1` 以上 (設定画面が DevloopSection を使う)
2. 検証コマンド 2 が終了コード 0
3. 検証コマンド 3 が終了コード 0
4. 検証コマンド 4 が終了コード 0

## 検証コマンド
1. `grep -c "DevloopSection" "src/app/(app)/settings/page.tsx"`
2. `pnpm typecheck`
3. `pnpm lint`
4. `pnpm build`
