# PBI-077: 古くなった記述の手直しと、.vitest/ を git の対象外にする

- 担当モデル: opencode deepseek-v4.1-flash（sonnet 相当、review normal） (select_model.py v11: modules=2 >= 2; scores novelty 0 / coupling 0 / ambiguity 0)
- 依存: PBI-076

## 目的
M2 で状況が変わったのに、文書に古いままの記述が 2 か所ある。また、テストの実行時に rtk が `.vitest/` フォルダを作るが、git の対象外になっていない。この 3 点を直す。

## 対象
- 変更 `docs/SETUP.md` の「9. MCP の口」の「守り」の節 (109 行付近): 「M1 で使えるのは `read` の … 3 ツール。`board`・`loop` のツールは今後追加する」という文を、今のツール (read: `list_nodes`・`get_project`・`get_board`・`is_stopped`、board: `create_item`・`move_item`・`update_item`・`comment_item`・`request_owner`、loop: `next_project`・`report_run`・`pause`) を並べる文に置き換える。ツール名は `src/lib/mcp/tools.ts` と `src/lib/mcp/devloop-tools.ts` で確かめる
- 変更 `docs/DESIGN.md` の「方針」の「データの正」(7 行付近): 「アプリの DB は表示用の一時保存で、消えても GitHub と Asana から作り直せる」の後ろに、「ただし MCP の口の 4 テーブル (`agent_tokens` など) と devloop の制御・実行の記録 (`dev_projects`・`devloop_control`・`devloop_runs`・`iterations`) は作り直せない運用データ」という趣旨を 1 文で足す
- 変更 `.gitignore`: 末尾に `.vitest/` の行を足す (説明のコメント 1 行付き)

## 触らない範囲
- 上の 3 か所以外の文書の内容、ソースコード

## 受け入れ条件
1. 検証コマンド 1 の出力が空 (「今後追加する」の記述が残っていない)
2. 検証コマンド 2 の出力が `1` 以上
3. 検証コマンド 3 の出力が `1`
4. 検証コマンド 4 の出力が空 (`.vitest/` が git の未追跡に出ない)

## 検証コマンド
1. `/usr/bin/grep -n "今後追加する" docs/SETUP.md`
2. `/usr/bin/grep -c "作り直せない" docs/DESIGN.md`
3. `/usr/bin/grep -cx ".vitest/" .gitignore`
4. `git status --short .vitest`

- 文体は既存に合わせる (常体、簡潔)。コミットはしない
