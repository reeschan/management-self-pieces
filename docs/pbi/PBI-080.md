# PBI-080: node.yaml の取り込みの仕組みを外す

- 担当モデル: opencode opencode-go/deepseek-v4.1-flash（sonnet 相当、review normal）
- 依存: なし

共通の決まりとモジュールの契約: `docs/pbi/_node_common.md` を最初に読み、従う。

## 目的
Node の正をアプリに移すため、`node.yaml` を読んで DB に反映する取り込みの仕組み一式と `/schema/node.json` を消す。Webhook と Cron のルートは、取り込みを呼ばずに動く形にしておく (つながりの更新は PBI-088 で足す)。

## 対象
- 削除: `src/lib/manifest/parse.ts`・`src/lib/manifest/json-schema.ts`・`src/lib/manifest/manifest.test.ts`
- 削除: `src/app/schema/node.json/` (ディレクトリごと)
- 削除: `src/lib/github/importer.ts`・`src/lib/github/importer.test.ts`
- 削除: `src/lib/import/` (ディレクトリごと: plan.ts・plan.test.ts・apply.ts・apply-result.ts・run.ts)
- 削除: `scripts/fixtures.test.ts` (PBI-089 で作り直す)
- 変更 `src/lib/github/types.ts`: `ImportedManifest`・`ImportError`・`ImportResult` と、`NodeManifest` の import を消す。`RepoRef`・`RepoFile`・`RepoSource` は残す
- 変更 `src/app/api/webhooks/github/route.ts`: 署名の確認と JSON の解析は今のまま残す。取り込み (`runRepoImport`) を呼ばず、200 で `{ ignored: "取り込みは廃止 (つながりの更新は今後追加)" }` を返す。`decideGithubAction` は呼ばない (`src/lib/github/webhook.ts` 自体は変えない)
- 変更 `src/app/api/cron/import/route.ts`: `runFullImport` を消す。認証と、監査ログ・回数制限の古い分の削除 (`purgeSafely`) は残し、応答は `{ auditPurged, rateLimitsPurged }`
- 変更 `scripts/seed.mts`: 中身を「fixtures の読み込みは作り直し中です」と stderr に出して終了コード 1 で終わる処理だけにする

## 触らない範囲
`src/lib/manifest/schema.ts`・`src/lib/manifest/kinds.ts` (他で使っているので残す)、`src/lib/github/webhook.ts` と `webhook.test.ts`、`src/lib/github/app.ts`、`src/db/`、`drizzle/`、`fixtures/`、`package.json`、上に無いファイル

## 受け入れ条件
1. 検証コマンド 1 の出力が `ok`
2. 検証コマンド 2 の出力が空 (一致 0 件で終了コード 1。出力の値で判定する)
3. 検証コマンド 3 (typecheck) の終了コードが 0
4. 検証コマンド 4 (test:unit) の終了コードが 0
5. 検証コマンド 5 (lint) の終了コードが 0

## 検証コマンド
リポジトリのルートから Git Bash で実行する。
1. `test ! -e src/lib/import && test ! -e src/lib/github/importer.ts && test ! -e src/lib/manifest/parse.ts && test ! -e src/lib/manifest/json-schema.ts && test ! -e src/app/schema/node.json && test ! -e scripts/fixtures.test.ts && echo ok`
2. `/usr/bin/grep -rlE "parseManifest|importAll|importRepo|runFullImport|runRepoImport|applyImportResult|nodeJsonSchema|ImportResult" src scripts --exclude=webhook.ts` (検証コマンドの不備を修正: webhook.ts の `importRepos` は PBI-088 で書き換える)
3. `pnpm typecheck`
4. `pnpm test:unit`
5. `pnpm lint`

## 補足
- 並列で PBI-081 が `src/lib/nodes/detail.ts` と `src/components/panel/node-panel.tsx` を直している。そこは触らない
- `yaml` パッケージは他でも使っているので package.json は変えない
- `.next/` に古い生成物があり typecheck が `schema/node.json` を探して落ちるときは、`.next/types` と `.next/dev/types` を消してから再実行してよい (生成物なのでコミット対象ではない)
