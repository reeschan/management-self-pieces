# PBI-081: パネルと詳細から取り込みエラーの表示を外す

- 担当モデル: opencode opencode-go/deepseek-v4.1-flash（sonnet 相当、review normal）
- 依存: なし

共通の決まりとモジュールの契約: `docs/pbi/_node_common.md` を最初に読み、従う。

## 目的
`import_errors` (取り込みの警告) は廃止する。テーブルを消す前に、詳細の読み出しとパネルの表示から外し、node.yaml を前提にした文言を直す。

## 対象
- 変更 `src/lib/nodes/detail.ts`: `import_errors` を読む処理と、`NodeDetail` の `importErrors` を消す。`node.sourceRepo` の型は `string | null` にする (今は常に文字列が入るが、PBI-082 で NULL になりうる)
- 変更 `src/components/panel/node-panel.tsx`: `PanelDetail` の `importErrors` と「取り込みの警告」の枠を消す。`sourceRepo` を `string | null` にし、「取り込み元: …」を「リポジトリ: …」(null なら「なし」) にする。図が無いときの文言「node.yaml の diagrams に図を追加すると表示されます」を「Node の編集画面で図のパスを足すと表示されます」にする

## 触らない範囲
`src/db/schema.ts` (テーブルは PBI-082 で消す)、`src/app/api/nodes/`、上の 2 ファイル以外

## 受け入れ条件
1. 検証コマンド 1 の出力が `0`
2. 検証コマンド 2 の出力が空 (一致 0 件で終了コード 1)
3. 検証コマンド 3 (typecheck) の終了コードが 0
4. 検証コマンド 4 (lint) の終了コードが 0

## 検証コマンド
リポジトリのルートから Git Bash で実行する。
1. `cat src/lib/nodes/detail.ts src/components/panel/node-panel.tsx | /usr/bin/grep -c "importErrors"`
2. `/usr/bin/grep -n "node.yaml\|取り込み元\|取り込みの警告" src/components/panel/node-panel.tsx`
3. `pnpm typecheck`
4. `pnpm lint`

## 補足
- 並列で PBI-080 が取り込みの仕組みを消している。typecheck がそちらの途中のファイルで落ちたら、その旨を報告に書く
