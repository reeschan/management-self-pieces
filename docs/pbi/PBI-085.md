# PBI-085: Node の入力の型と、Node のサービス (候補・登録・編集・削除) を作る

- 担当モデル: agent sonnet high（sonnet 相当、review deep）
- 依存: PBI-082, PBI-084

共通の決まりとモジュールの契約: `docs/pbi/_node_common.md` を最初に読み、従う。

## 目的
Node をアプリで登録・編集・削除する中心のモジュールを作る。画面と seed はこれを呼ぶ。合意済みの seam なので、テストを先に書く。

## 対象
- 新規 `src/lib/nodes/input.ts`: `docs/pbi/_node_common.md` の「Node の入力」のとおり。部品 (`NodeId`・`RepoPath`・`Relation`・`Diagram`・`NodeStatus` と kind の登録表) は `src/lib/manifest/schema.ts`・`kinds.ts` から import する。kind ごとの meta は `kinds[kind].meta` で検証する (superRefine など)
- 変更 `src/lib/manifest/schema.ts`: `NodeManifest` (node.yaml の定義) と、その型を消す。他の部品は残す。説明文の「node.yaml」は消す
- 新規 `src/lib/nodes/service.ts`: 契約のとおり `createNodeService` と `NodeServiceError` を作る。振る舞い:
  - `listCandidates`: `source().listRepos()` のうち、どの Node の `repoId` とも、`sourceRepo` (大文字小文字を区別しない) とも一致しないもの。例外は `github_unavailable`
  - `draftFromRepo(fullName)`: `getRepo` が null なら `not_found`、例外なら `github_unavailable`。id はリポジトリの名前 (owner を除く) を英小文字にし、`[a-z0-9-]` 以外をハイフンにし、連続するハイフンを 1 つにし、前後のハイフンを除き、63 文字で切ったもの (空なら `node`)。title は名前、summary は description を 200 文字で切ったもの (無ければ "")、tags は topics、links は `{ repo: htmlUrl }` に homepage があれば `homepage` を足す、`detailPath` は `README.md` が `getFile` で読めれば `"README.md"`、読めなければ null、diagrams は空、kind は `app`、status は `active`、meta は空、relations は空、repo は `{ id, fullName }`
  - `create(input)`: `NodeCreateInput` で検証 (失敗は `invalid`)。id が既にあれば `id_taken`。repo があり、同じ `repoId` か同じ名前 (大文字小文字を区別しない) の Node があれば `repo_taken`。関係の先が無ければ `relation_target_missing`。nodes に入れ (`repoReachable` true、`createdAt`・`updatedAt` は now)、関係を入れる。**リポジトリの無い Node の登録では `source()` を呼ばない**
  - `update(id, input)`: 無ければ `not_found`。`NodeUpdateInput` で検証。関係の先を確かめる。項目と `updatedAt` を更新し、その Node から出る関係を消してから入れ直す。id・リポジトリ・`repoReachable`・`createdAt` は変えない
  - `deletionBlockers(id)`: `external_refs` に行があれば `asana`、`dev_projects`・`devloop_runs`・`iterations` のどれかに行があれば `devloop`
  - `remove(id)`: 無ければ `not_found`。blockers があれば `has_records` (message は「Asana との対応か devloop の記録があるため消せません。status を archived にしてください」の趣旨)。無ければ消す (向いた関係は cascade で消える)
- 新規 `src/lib/nodes/service.test.ts`: **実装より先に書く**。PGlite と `createFakeRepoSource` を使い、上の振る舞いをそれぞれ確かめる (少なくとも: 候補から結び付き済みが除かれる (id 一致・名前の大文字小文字違い)、初期値の各項目、README が無いと detailPath が null、id_taken、repo_taken、relation_target_missing、自分への関係は invalid、リポジトリの無い Node で detailPath があると invalid、kind の meta の型違いは invalid、リポジトリの無い Node の登録で source が呼ばれない、update が関係を置き換え id とリポジトリを変えない、update の not_found、blockers の asana と devloop、remove の has_records、remove で向いた関係も消える)
