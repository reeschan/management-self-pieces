# PBI-088: Webhook と Cron を、つながりの更新に置き換える

- 担当モデル: opencode opencode-go/deepseek-v4.1-flash（sonnet 相当、review normal）
- 依存: PBI-086

共通の決まりとモジュールの契約: `docs/pbi/_node_common.md` を最初に読み、従う。

## 目的
取り込みの代わりに、GitHub の Webhook と毎日の Cron で、Node とリポジトリのつながり (名前と届くか) を直す。

## 対象
- 変更 `src/lib/github/webhook.ts`: `decideGithubAction` の戻り値を `GithubAction[]` にし、`GithubAction` を `{ kind: "refresh"; repos: RepoKey[] } | { kind: "unreachable"; repos: RepoKey[] }` にする (`RepoKey` は `@/lib/nodes/repo-link` から)。何もしないときは空の配列 (理由はログ用に別に返してよい)。決まり:
  - `repository`: action が `renamed`・`transferred`・`archived`・`unarchived` → `refresh` (`repository` の `id`・`full_name`)。`deleted` → `unreachable`。他は空
  - `installation_repositories`: `repositories_added` が空でなければ `refresh`、`repositories_removed` が空でなければ `unreachable` (両方あれば 2 つ)
  - `installation`: action が `deleted` で `repositories` があれば `unreachable`。他は空
  - `push` とその他: 空
  - payload は今と同じく Zod で検証し、形が違えば空
  - `isAuthorizedCron` は変えない
- 変更 `src/lib/github/webhook.test.ts`: 上の決まりのテストに書き換える (**実装より先に**)。`push` が空になることを含める
- 変更 `src/app/api/webhooks/github/route.ts`: 署名の確認と JSON の解析は今のまま。`decideGithubAction` の結果ごとに `createRepoLinkService({ db: getDb(), source: createRepoSource, now: () => new Date() })` の `refreshRepos`・`markUnreachable` を呼び、結果の数を JSON で返す。空なら `{ ignored: <理由> }`。失敗は 500 (message は返さず、console.error に出す)
- 変更 `src/app/api/cron/import/route.ts`: 認証のあとで `refreshAll()` を呼び、そのあと今の `purgeSafely` を行う。`refreshAll` の失敗は 500。応答は `{ ...summary, auditPurged, rateLimitsPurged }`。パスは変えない (vercel.json の Cron がこのパスを呼ぶため)。ファイルの先頭にコメントで「パス名は以前の取り込みの名残」と書く

## 触らない範囲
Webhook の署名の確認、Cron の認証、`vercel.json`、`src/lib/nodes/repo-link.ts` (使うだけ)、上に無いファイル

## 受け入れ条件
1. 検証コマンド 1 が pass する
2. 検証コマンド 2 の出力が空 (一致 0 件で終了コード 1)
3. 検証コマンド 3 の出力が `1` 以上
4. 検証コマンド 4 (typecheck) の終了コードが 0
5. 検証コマンド 5 (lint) の終了コードが 0

## 検証コマンド
リポジトリのルートから Git Bash で実行する。
1. `pnpm vitest run src/lib/github/webhook.test.ts`
2. `/usr/bin/grep -n "import-repo\|取り込みは廃止" src/lib/github/webhook.ts src/app/api/webhooks/github/route.ts`
3. `/usr/bin/grep -c "refreshAll" 'src/app/api/cron/import/route.ts'`
4. `pnpm typecheck`
5. `pnpm lint`

## 補足
- 並列で PBI-087 と PBI-090 が `src/lib/nodes/transfer.ts`・`src/app/(app)/nodes/`・`src/lib/nodes/server.ts` を作っている。そこは触らない
- GitHub の Webhook の payload: `repository` イベントは `repository: { id, full_name }`、`installation_repositories` は `repositories_added` / `repositories_removed: { id, full_name }[]`、`installation` は `repositories?: { id, full_name }[]`
