# PBI-092: 設定画面に Node の書き出しと読み込みを足す

- 担当モデル: opencode opencode-go/deepseek-v4.1-flash（sonnet 相当、review normal）
- 依存: PBI-087

共通の決まりとモジュールの契約: `docs/pbi/_node_common.md` を最初に読み、従う。

## 目的
DB が消えたときの備えとして、設定画面から Node を JSON で書き出し、プレビューを見てから読み込めるようにする。

## 対象
- 新規 `src/app/(app)/settings/node-transfer-actions.ts` (`"use server"`): `exportNodesAction(): Promise<string>` (`exportNodes` の結果を整形した JSON 文字列)、`previewImportAction(text: string): Promise<ImportPreview>`、`importNodesAction(text: string): Promise<{ added: number; updated: number }>`。最初に `getAllowedSession()`。`text` は 1,000,000 文字を超えたら「ファイルが大きすぎます」。`JSON.parse` に失敗したら `{ ok: false, errors: ["JSON として読めません"] }` (import では Error)。`NodeServiceError` はその message で、それ以外は「処理に失敗しました」。読み込みが成功したら `revalidatePath("/")`・`revalidatePath("/nodes")`
- 新規 `src/components/settings/node-transfer-section.tsx` (クライアントコンポーネント): 「書き出す」ボタン (`exportNodesAction` の文字列を Blob にし、`nodes-YYYYMMDD.json` としてダウンロード)。「読み込む」: ファイルを選ぶ → `previewImportAction` → 「追加 n 件・更新 n 件」かエラーの一覧を出す → 「この内容で読み込む」ボタンで `importNodesAction` → 結果を出す。注意書き「JSON に無い Node は消えません」
- 変更 `src/app/(app)/settings/page.tsx`: devloop の節の下に「Node の書き出しと読み込み」の節 (`<section aria-labelledby=...>` と `<h2>`、既存の節と同じ形) を足し、`NodeTransferSection` を置く

## 触らない範囲
設定画面の既存の節の中身、`src/lib/nodes/` (使うだけ)、上に無いファイル

## 受け入れ条件
1. 検証コマンド 1 の出力が `3` 以上
2. 検証コマンド 2 の出力が `1` 以上
3. 検証コマンド 3 (typecheck) の終了コードが 0
4. 検証コマンド 4 (lint) の終了コードが 0
5. 検証コマンド 5 の出力の 1 行目が `exit=0`

## 検証コマンド
リポジトリのルートから Git Bash で実行する。
1. `/usr/bin/grep -c "getAllowedSession" 'src/app/(app)/settings/node-transfer-actions.ts'`
2. `/usr/bin/grep -c "NodeTransferSection" 'src/app/(app)/settings/page.tsx'`
3. `pnpm typecheck`
4. `pnpm lint`
5. `pnpm build > docs/pbi/verify/build.$$.log 2>&1; echo "exit=$?"; /usr/bin/grep -E "/nodes" docs/pbi/verify/build.$$.log | head -n 5`
