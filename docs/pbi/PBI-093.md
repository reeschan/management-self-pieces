# PBI-093: ナビゲーション・パネル・空の画面から Node 画面へつなぐ

- 担当モデル: opencode opencode-go/deepseek-v4.1-flash（sonnet 相当、review normal）
- 依存: PBI-082, PBI-090

共通の決まりとモジュールの契約: `docs/pbi/_node_common.md` を最初に読み、従う。

## 目的
Node 画面への入口を作り、3D のパネルにリポジトリの状態と編集へのリンクを出す。node.yaml を前提にした案内を直す。

## 対象
- 変更 `src/app/(app)/layout.tsx`: ナビゲーションの「ダッシュボード」と「Owner 判断」のあいだに `<Link href="/nodes">Node</Link>` を足す (既存の Link と同じクラス)
- 変更 `src/components/panel/node-panel.tsx`:
  - `PanelDetail.node` に `repoReachable: boolean` を足す (`/api/nodes/[id]` が返す `loadNodeDetail` の結果に PBI-082 で入っている)
  - 概要のタブに「編集」リンク (`/nodes/<id>/edit`) を足す
  - リポジトリがあり `repoReachable` が false なら、「リポジトリに届きません」の印を出す
  - 詳細のタブ: リポジトリが無い Node では「リポジトリの無い Node には詳細がありません」と出す (読み込み失敗の文言と分ける)
- 変更 `src/components/graph/dashboard.tsx`: Node が 0 件のときの案内から node.yaml と `pnpm db:seed` の記述を外し、「Node 画面から登録してください」と `/nodes` へのリンクにする

## 触らない範囲
パネルの他のタブ (看板・開発ループ・イテレーション)、`src/lib/`、上に無いファイル

## 受け入れ条件
1. 検証コマンド 1 の出力が `1` 以上
2. 検証コマンド 2 の出力が `1` 以上
3. 検証コマンド 3 の出力が空 (一致 0 件で終了コード 1)
4. 検証コマンド 4 (typecheck) の終了コードが 0
5. 検証コマンド 5 (lint) の終了コードが 0

## 検証コマンド
リポジトリのルートから Git Bash で実行する。
1. `/usr/bin/grep -c 'href="/nodes"' 'src/app/(app)/layout.tsx'`
2. `/usr/bin/grep -c "repoReachable" src/components/panel/node-panel.tsx`
3. `/usr/bin/grep -n "node.yaml\|db:seed" src/components/graph/dashboard.tsx src/components/panel/node-panel.tsx`
4. `pnpm typecheck`
5. `pnpm lint`

## 補足
- 並列で PBI-089・091・092 が動いている。そこは触らない
