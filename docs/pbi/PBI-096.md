# PBI-096: devloop の操作のエラーを戻り値で返す (アクションと、看板・Owner 判断の画面)

- 担当モデル: opencode opencode-go/deepseek-v4.1-flash max（sonnet 相当、review normal）
- 依存: なし

## 目的
Next.js は本番のビルドで、サーバーアクションが throw した Error の message を消す。devloop の操作 (看板の準備・設定の変更・一時停止・全体停止・1 日の上限・Owner 判断への回答) は失敗の理由を throw で伝えているため、本番では「Inbox が上限の…」のような理由が画面に出ない。PBI-095 で Node の操作に入れた `ActionResult` の形に、devloop のアクションをそろえる。この PBI はアクションのファイルと、看板・Owner 判断の 2 画面。設定のタブ・設定画面の 2 画面は PBI-097 で直す。

## 対象
- 変更 `src/app/(app)/devloop/actions.ts`: 7 つの関数の戻り値を次に変える。`throw` を残さない
  - `prepareBoard`: `Promise<ActionResult<{ projectId: string; url: string | null; created: Section[] }>>`
  - `updateDevloopSettings`・`pauseNode`・`resumeNode`: `Promise<ActionResult<ControlSettings>>`
  - `setGlobalStop`・`setDailyLimit`・`answerOwnerDecision`: `Promise<ActionResult<null>>`
  - セッションが無ければ `UNAUTHORIZED`。`parseInput` は throw せずに結果を返す形に変える (失敗の文言は「入力が正しくありません」のまま)
  - `withUserError` は throw せず `ActionResult<T>` を返す形に変える: `BoardLimitError` は `limitMessage`、`BoardError` は `boardMessage` の文言を `{ ok: false, message }` で返し、それ以外は `actionError(error, "[devloop:actions] 処理に失敗しました")` を返す。`limitMessage`・`boardMessage` の文言は変えない
  - `revalidatePath` は成功したときだけ (今と同じパス)
  - ファイル先頭のコメント「例外は利用者向けの文言に変えて投げ直す」を、戻り値で返す旨に直す
- 変更 `src/components/panel/devloop/board-tab.tsx`: `prepareBoard` の戻り値を見て、`ok: false` なら `setError(result.message)`。try/catch の例外のときは「通信に失敗しました」
- 変更 `src/components/owner/owner-answer-form.tsx`: `answerOwnerDecision` の戻り値を見て同じようにする。`ok: false` のときは入力欄を空にしない (成功のときの処理をしない)

## 触らない範囲
`src/components/panel/devloop/loop-tab.tsx`・`src/components/settings/devloop-section.tsx` (PBI-097)。`src/lib/action-result.ts` (使うだけ)。`src/lib/devloop/`・`src/lib/tracker/` (使うだけ)。`src/app/(app)/settings/`・`src/app/(app)/actions.ts`・`src/app/(app)/nodes/`。上に無いファイル

## 受け入れ条件
1. 検証コマンド 1 の出力が空 (一致 0 件で終了コード 1)
2. 検証コマンド 2 の出力が空 (一致 0 件で終了コード 1)
3. 検証コマンド 3 の出力が 7 以上 (7 つの関数の戻り値の型に `ActionResult` が出る)
4. 検証コマンド 4 (typecheck) の終了コードが 0
5. 検証コマンド 5 (lint) の終了コードが 0
6. 検証コマンド 6 (test:unit) の終了コードが 0

## 検証コマンド
リポジトリのルートから Git Bash で実行する。
1. `/usr/bin/grep -n "throw " 'src/app/(app)/devloop/actions.ts'`
2. `/usr/bin/grep -n "e.message\|err.message" src/components/panel/devloop/board-tab.tsx src/components/owner/owner-answer-form.tsx`
3. `/usr/bin/grep -c "ActionResult" 'src/app/(app)/devloop/actions.ts'`
4. `pnpm typecheck`
5. `pnpm lint`
6. `pnpm test:unit`
