# PBI-097: devloop の設定のタブと設定画面で、アクションの戻り値からエラーを出す

- 担当モデル: opencode opencode-go/deepseek-v4.1-flash max（haiku 相当、review normal）
- 依存: PBI-096

## 目的
PBI-096 で devloop のアクションが throw をやめて `ActionResult` を返すようになった。Node のパネルの「ループ」タブと設定画面の devloop の欄は、まだ例外だけを見ているので、失敗しても成功として扱ってしまう。戻り値の ok を見てエラーを出すように直し、本番のビルドでも失敗の理由が画面に出るようにする。

## 対象
- 変更 `src/components/panel/devloop/loop-tab.tsx`: `Run` 型と `run` を、`action: () => Promise<ActionResult<unknown>>` を受けて、`ok: false` なら `setError(result.message)` して onSuccess・onChanged を呼ばない形に変える。try/catch の例外のときは「通信に失敗しました」。`updateDevloopSettings`・`pauseNode`・`resumeNode` の呼び出しはそのまま `run` に渡す
- 変更 `src/components/settings/devloop-section.tsx`: 同じく `run` (または相当する補助関数) を変え、`setGlobalStop`・`setDailyLimit` の戻り値の ok を見る。例外のときは「通信に失敗しました」

## 触らない範囲
`src/app/(app)/devloop/actions.ts` (PBI-096 で済み。使うだけ)。`src/lib/action-result.ts`。画面の見た目・文言 (エラーの出し方以外)。上に無いファイル

## 受け入れ条件
1. 検証コマンド 1 の出力が空 (一致 0 件で終了コード 1)
2. 検証コマンド 2 の出力が 2 以上 (2 つのファイルとも `ActionResult` を使う。ファイルごとに 1 以上)
3. 検証コマンド 3 (typecheck) の終了コードが 0
4. 検証コマンド 4 (lint) の終了コードが 0
5. 検証コマンド 5 (test:unit) の終了コードが 0
6. 検証コマンド 6 の出力の 1 行目が `exit=0`

## 検証コマンド
リポジトリのルートから Git Bash で実行する。
1. `/usr/bin/grep -n "e.message\|err.message" src/components/panel/devloop/loop-tab.tsx src/components/settings/devloop-section.tsx`
2. `/usr/bin/grep -c "ActionResult" src/components/panel/devloop/loop-tab.tsx src/components/settings/devloop-section.tsx`
3. `pnpm typecheck`
4. `pnpm lint`
5. `pnpm test:unit`
6. `pnpm build > docs/pbi/verify/build.$$.log 2>&1; echo "exit=$?"`

## 補足
- 検証コマンド 2 は `ファイル:件数` の 2 行を出す。どちらの行も 1 以上なら pass
- 型は `import type { ActionResult } from "@/lib/action-result"` で読む
- 並列で動く PBI は無い
